
# Besouro Mecânico e Caracol Robótico

Trabalho Prático de Computação Gráfica — 2026/02.

## Objetivo

Desenvolver uma cena tridimensional com dois personagens
animados e uma interação coordenada.

## Temas selecionados

- Tema 29: Besouro Mecânico
- Tema 30: Caracol Robótico

## Tecnologias

- Python 3.11
- Pygame
- PyOpenGL
- NumPy
- Pillow

## Situação do desenvolvimento

Ambiente Python configurado e teste inicial de janela
OpenGL realizado com sucesso.

Próximas etapas: integração do framework do livro,
modelagem dos personagens e desenvolvimento da cena.

## Referência principal

STEMKOSKI, Lee; PASCALE, Michael.
Developing Graphics Frameworks with Python and OpenGL.
CRC Press, 2022.
